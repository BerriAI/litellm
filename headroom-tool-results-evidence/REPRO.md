# Reproduction

Run from the evidence directory. Set `HR_MASTER_KEY` locally; do not store its value in this bundle. The proxy YAML files are under `run/*.yaml` and reference `os.environ/ANTHROPIC_API_KEY` and `os.environ/OPENAI_API_KEY`.

Start Headroom on the local interface:

```sh
setsid nohup headroom proxy --host 127.0.0.1 --port 8787 > headroom.log 2>&1 < /dev/null &
```

```sh
export HR_MASTER_KEY='<set locally>'
```

K1_chat through Chat on port 4034:

```sh
curl --silent --show-error -H "Authorization: Bearer $HR_MASTER_KEY" \
  -H 'content-type: application/json' \
  --data-binary @run/res/final.K1_chat.client_req.json \
  http://127.0.0.1:4034/v1/chat/completions
```

N4 through `/v1/messages` on port 4034:

```sh
curl --silent --show-error -H "Authorization: Bearer $HR_MASTER_KEY" \
  -H 'content-type: application/json' \
  --data-binary @run/res/final.N4_msgs_iserror_false_block.client_req.json \
  http://127.0.0.1:4034/v1/messages
```

K1_resp through `/v1/responses` on port 4034:

```sh
curl --silent --show-error -H "Authorization: Bearer $HR_MASTER_KEY" \
  -H 'content-type: application/json' \
  --data-binary @run/res/final.K1_resp.client_req.json \
  http://127.0.0.1:4034/v1/responses
```

(cd wt-base  && PYTHONPATH=$PWD python -m litellm.proxy.proxy_cli --config run/base.yaml   --port 4021)
(cd wt-base  && PYTHONPATH=$PWD python -m litellm.proxy.proxy_cli --config run/basefo.yaml --port 4022)
