# litellm internal architecture

A documentation series on how the litellm codebase is put together, what it seems to be aiming for, and where it falls short of that today. Written for people changing the code, not for users of the product. Checked against `BerriAI/litellm` `main` at `13118948` on 2026-10-15

Diagrams are hand-laid-out SVG files in [diagrams/](diagrams/), generated by the scripts in [tools/diagrams/](tools/diagrams/). Edit a script and rerun it to change a picture

## Start here

[explanation/01-system-overview.md](explanation/01-system-overview.md) gives the big picture and the seven design principles the code implies, with a one-line verdict on each. Then pick by what you need
