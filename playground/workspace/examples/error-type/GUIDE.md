# In-repo dependency app

This standalone binary package imports a type directly from LiteLLM's Rust crate.

- [Open the main function](error-type://src/main.rs#L3)
- [Open the report module](error-type://src/report.rs#L1)
- [Open its Cargo manifest](error-type://Cargo.toml#L1)

Run the example to print the fully qualified name of `litellm_core::Error`. No model or network request is involved.
