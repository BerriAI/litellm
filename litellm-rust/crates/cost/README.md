# litellm-cost

This crate holds the price data model that `litellm-model-catalog` lowers each catalog entry into, plus the usage, call context and priced outcome types. `calculate` prices a call's token usage over a row's `Prices` and `Adjustments`, one `Line` per meter with usage, and names the meter whose rate a line borrowed in `fallback_from`. Character, second and per-unit meters land in later PRs and are reported as `missing` until then. `UnitPrice` is USD per unit and `Usd` is an amount, and only the operations that make sense between them exist, so a price is never added to an amount. `Prices::band` picks the prompt band the way Python's `_get_token_base_cost` does
