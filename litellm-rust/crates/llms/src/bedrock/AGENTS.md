# rules

- Owns Bedrock-wide policy: region resolution, the runtime endpoint template, and SigV4 or bearer-token auth through `litellm-auth-aws`
- Paths and wire types shared by Bedrock's formats come from `litellm_llms_types::providers::bedrock`
