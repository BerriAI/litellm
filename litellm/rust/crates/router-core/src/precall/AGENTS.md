- This folder is `enable_pre_call_checks` (Python `Router._pre_call_checks`), one switch over a fixed set of filters run on the whole candidate group before a pick. `optional_pre_call_checks` lives in `../pre_call_checks/`, never here
- `mod.rs` holds the facts (`PreCallFacts`, `DeploymentFacts`) and `filter`, which runs the stages in order and then picks the error. Each stage is its own file here: `context_window.rs`, `region.rs` and `params.rs`
- A stage is a pure function of the facts and the deployments it is handed. It makes no host call, touches no cache and is not async
- The host reports what it alone can read, as it reads it, and never decides which params count as requested, lacking or rejected. `RouterHost::pre_call_facts` reports the token count, the context windows, the live `litellm.drop_params`, the request's own call settings and how the request sends each of `CHECKED_PARAMS` (`Sent`). `requested` then names the params the request asks for, and only when it names one does `RouterHost::unsupported_params` report which deployments do not support them, so a request that asks for none costs no lookup
- A deployment's call settings (`drop_params`, `allowed_openai_params`, `additional_drop_params`) are typed once, as `LitellmParams::call_settings` in `router-types`, and the request's arrive as the same type. A key the request sends replaces the deployment's, a `null` included, because the call itself reads `{**litellm_params, **kwargs}`
- Stage order is behavior. A deployment the context window drops is never checked for region, params run only on what is left, and `UnsupportedParams` wins only when nothing overflowed and every pool deployment rejects the param
- A new stage is a new file plus one call in `filter`, with its cases as `filter` behavior tests in `mod.rs`
- Python's `Router._pre_call_checks` takes deployment records instead of a pick. It runs this same `filter` through python-bridge's `pre_call_filter`, so no rule is written twice
- The gateway answers these facts in `gateway/src/host/precall.rs`, and `admit` sends to Python any request whose facts it cannot report (a key's `allowed_model_region`, a body with `response_format`)
